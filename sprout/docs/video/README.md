# Video kit

Ready-made pieces for the 3-minute demo video (see [`../DEMO_SCRIPT.md`](../DEMO_SCRIPT.md)).

| File | Use |
|---|---|
| `card-hook.png` | 0:00-0:12, the opening statistic (Common Sense Media, Oct 2026) |
| `card-title.png` | Optional, a 2-3 s title between the hook and the welcome screen |
| `card-end.png` | 2:45-2:55, the end card with the repo and live links |
| `captions.srt` | English captions timed to the script; upload to YouTube (Subtitles > Upload file > With timing), then adjust timings to the final cut |
| `card.html` | Source of the cards; open `card.html#title`, `#hook` or `#end` in Chrome at 1920x1080 to re-render |

All cards are 1920x1080 PNG, in the app's night-garden colours.
