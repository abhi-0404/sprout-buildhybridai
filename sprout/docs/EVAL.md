# Sprout deterministic eval

Generated by `pnpm eval`. All questions are synthetic (no real people, schools or contact details).
Worst case: every question is forced to the cloud, with and without an on-device model, and no help
from the model's name detection. Real runs add the on-device model on top of this layer.

## Development set

Used while the rules were written, so these numbers are optimistic by construction. The eval test asserts zero leaks here.

Source: `shared/eval/questions.jsonl` (201 synthetic questions).

| Metric | Result |
|---|---|
| Private details that must stay hidden | 87 across 76 questions |
| Cloud prompts inspected | 684 |
| **Private details that reached the cloud** | **0** |
| Clean questions changed by redaction (over-redaction) | 0 of 95 |
| Urgent distress caught (deterministic layer) | 19 of 19 |
| Concern distress caught (deterministic layer) | 11 of 11 |
| False alarms on non-distress questions | 0 of 171 |
