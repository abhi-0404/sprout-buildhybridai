  Main description
On-device models are fast, private and free to run, but they aren't on every device. #BuildHybridAI challenges you to build apps that use both. Using the Firebase AI Logic Hybrid Inference SDK, your app runs prompts on-device when a local model is available and falls back to the cloud when it isn't.
Build for at least one platform: Web (Chrome) or Android with Gemini Nano 4, or iOS with Apple Foundation Models, all through Firebase AI Logic. Want to go further? Apps that run across multiple platforms will be given strong consideration for the Grand Prize, since that's where a single hybrid SDK really shines. An outstanding single-platform app can still win. For example: a notes app that summarizes on-device offline and hands long documents to the cloud. New projects and significantly updated existing apps are both eligible, and the competition is open to individuals, teams and organizations in most countries (see the Official Rules).
Why join?
$30,000 in cash prizes, including a $10,000 Grand Prize and a $3,000 award for the best app on each platform
Top winners get an interview and a featured blog post from the Firebase team
Learn hybrid inference: one SDK for on-device and cloud AI across Web, Android and iOS
Bring an existing app — it's eligible if significantly updated during the competition
Start free: text inference with Firebase AI Logic is free within usage limits, and you can request a Google Account Quota for advanced features such as image generation

        Requirements
What to Build
Build a Gen AI application using Firebase AI Logic along with supported firebase products such as: AppCheck, RemoteConfig, Firestore and Authentication.
Build for one of these platforms:
Web (Chrome): Gemini Nano 4 via Firebase AI Logic. Build a web app or a Chrome extension.
Android: Gemini Nano 4 via Firebase AI Logic.
iOS: the Apple Foundation Models API for local execution via Firebase AI Logic.
Firebase AI Logic requires App Check; debug tokens are accepted in submissions. You're encouraged to use other Firebase products, such as Remote Config, Firestore and Authentication.
How to Build
Build with any AI coding tool or IDE you like, such as Antigravity, Android Studio, Codex or Cursor, as long as your app's AI runs on Firebase AI Logic. Google tools like Antigravity are recommended. Coding agents work best with Firebase Agent Skills, which come built into Antigravity and Android Studio.

Google Account Quota (optional)

Accounts aren't guaranteed and are approved at Google's discretion. You're responsible for any fees beyond the provisioned quota, including use after the 4 days end.
Request data is processed under the Google Privacy Policy, and Google Cloud developer tools are subject to their license terms.

      Judging Criteria
        Technological Implementation: 
        How well is the project built, and how effectively does it use Firebase AI Logic hybrid inference as part of the solution?
        Design:
        Does the project deliver a complete, coherent product experience, not just a technical proof of concept?
        Potential Impact: 
        Does the project make a credible, specific case for solving a real problem for a real audience, and does the solution address it based on what's demonstrated?
        Quality of the Idea: 
        Is this a creative, non-obvious use of Firebase AI Logic, and does the team show genuine understanding of the problem space?
