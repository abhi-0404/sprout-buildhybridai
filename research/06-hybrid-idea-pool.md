# Round 2: hybrid-native mechanics and 30-idea pool

## Mechanics (device and cloud do different jobs)
| # | Mechanic | Device | Cloud |
|---|---|---|---|
| M1 | Instant draft, then upgrade | Answers in under 1s | Replaces it with a diff |
| M2 | Always-on watcher | Checks every item, free | Called only when worth it |
| M3 | Privacy firewall | Strips PII | Sees only the cleaned text |
| M4 | Personal memory stays local | Keeps history, sends traits | Personalizes from the traits |
| M5 | Compile once, run many | Runs a checklist offline many times | Writes a compact JSON rubric (Search/URL) |
| M6 | Device as referee | Checks cloud output against local truth | Gets re-asked |
| M7 | Capture now, combine later | Records offline | Synthesizes when online |
| M8 | Visible cost/privacy dial | Shows inferenceSource and cost | Used per the user's setting |
| M9 | Mesh of phones | Each phone infers locally | Firestore aggregates the results |
| M10 | Cloud teaches the device | Runs the work | Grades samples, pushes Remote Config |
| M11 | Device keeps a secret | Holds hidden info | Supplies shared content |

## Notes
- **Already saturated:** thrift scanners (15+ apps), board-game rules referees (Ludovik, Rulecraft, etc.), murder-mystery apps, and scavenger hunts.
- **Checkpoint evidence:** about 46% of car seats are misused (NHTSA, attribution varies), and inspections are by appointment only. https://www.nhtsa.gov/document/additional-analysis-national-child-restraint-use-special-study-child-restraint-misuse
- **Aftermath evidence:** after Hurricane Helene, 36.7% of cell sites in the affected Florida areas were out, and about 82% of towers in Buncombe County were offline. https://www.everycrsreport.com/reports/IF12779.html

## Outcome
The user wants a **broad everyday consumer app**. Checkpoint and Aftermath were judged too niche for that brief.
