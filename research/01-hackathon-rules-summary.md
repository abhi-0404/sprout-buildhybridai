# #BuildHybridAI 2026: rules summary

Source: https://firebasehybridaihackathon.devpost.com (fetched 2026-11-13). Full text is in `00-hackathon-official/`.

## Basics
- **Sponsor:** Google, administered by Devpost.
- **Prizes:** $30,000 in cash.
- **Submission period:** Nov 11 2026, 1:30 PM PT, to **Nov 30 2026, 2:00 PM PT**.
- **Judging:** Dec 10-16 2026. **Winners announced:** around Dec 21 2026.
- **Participants:** about 1,980 registered as of Nov 13-14.

## What to build
A Gen AI app using **Firebase AI Logic hybrid inference**: the on-device model runs when it is available, and the app falls back to the cloud otherwise.
- **Web (Chrome):** Gemini Nano. Can be a web app or a Chrome extension.
- **Android:** Gemini Nano 4.
- **iOS:** Apple Foundation Models.
- **Multi-platform is preferred.** It gets "strong consideration" for the Grand Prize, but an outstanding single-platform app can still win.
- **App Check is required.** Debug tokens are accepted.
- **Encouraged:** Remote Config, Firestore, Auth.
- **Eligible projects:** new projects, or existing ones that were significantly updated during the period (include a summary of what was built).

## Submission requirements (Stage 1, pass/fail)
- A text description covering: how Firebase AI Logic is used, the features, and the value proposition.
- A public GitHub or GitLab repo:
  - all source code plus setup instructions;
  - an open-source license visible in the About section (Apache preferred);
  - Firebase AI Logic **imported and actually called at runtime**.
- A YouTube demo video:
  - public;
  - 3 minutes or less (judges only watch the first 3 minutes);
  - in English or with English subtitles;
  - shows the app working on the target platform(s).
- A hosted demo or test build is strongly encouraged. Judges may score from the video and text alone.
- The app must be free to use.
- The repo and submission must not contain production keys, secrets or personal data.

## Judging (Stage 2)
- Four criteria, **equally weighted**, each scored 1-5 and then averaged:
  1. **Technological Implementation:** how well the project is built, and how effectively it uses hybrid inference.
  2. **Design:** a complete, coherent product, not a proof of concept.
  3. **Potential Impact:** a credible, specific real problem for a real audience, addressed in what is demonstrated.
  4. **Quality of the Idea:** a creative, non-obvious use of Firebase AI Logic, with a genuine understanding of the problem space.
- **Ties** are broken by comparing scores criterion by criterion in the order above, so Tech comes first.
- The highest score in each category wins that category. The highest score overall wins the Grand Prize.
- A project can win the Grand Prize plus one "Best of" prize.
